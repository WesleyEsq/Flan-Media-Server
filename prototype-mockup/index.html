Flan Media Server - Quick Help

100% Offline, Zero-Bloat Media Server:

  • Navigation: All browsing is handled strictly via the left sidebar (Video and Books).
  • Fixed Directories: Drop video folders in ./media/video and books in ./media/books.
  • Direct Playback: Videos stream with kernel zero-copy without transcoding to preserve SBC CPU and SD card life.
  • Storage Guard: Maximum 3 concurrent streams allowed to prevent USB disk head thrashing.
Tip: Press [ Manage Server ] at the bottom of the sidebar to rescan files or check system metrics.

About Flan

Flan is a self-hosted personal media server designed for streaming video files and reading digital books across devices on your local home network.

The server runs on your local computer, SBC, or home server (such as an Orange Pi 4 Pro) and delivers content directly to web browsers on your phones, tablets, laptops, and televisions. It operates entirely on your local network with zero external account requirements or third-party cloud services.

Instead of CPU-intensive transcoding, Flan streams videos natively via standard HTTP 206 Range requests delegating directly to Linux kernel zero-copy file transmission (sendfile).

Navigating the Interface

The application interface consists of a persistent top header and a main navigation bar:

  • Top Header:
    • Brand Title: Clicking Flan Media Server on the top-left returns you to the main video catalog.
    • Help Button (?): Opens this offline user handbook.
    • Profile Avatar: Opens your account menu to switch profiles, select an avatar companion, update your PIN, or log out.
  • Navigation Rail: (Located on the left of desktop screens and at the bottom of mobile screens)
    • Search: Opens full-canvas search across all video and book titles. Access via rail button or keyboard shortcut / or Ctrl+K.
    • Video: Displays your video collection. Use the top filter buttons to quickly view Movies, Series, or items currently in progress.
    • Books: Displays your digital reading library. Use the filter buttons to switch between EPUB books, PDF documents, or items currently being read.
    • Manage: Server administration page for configuring storage folders, scanning media, and managing household accounts (available to administrators).

Watching Videos & Player Controls

Click any video card in the catalog to open its detail view and begin playback. Videos that you have started watching appear automatically at the top of the video catalog under Continue Watching with a Resume button.

Browser Playback: Videos encoded with standard web codecs (such as H.264 video with AAC audio, or WebM) play directly inside your web browser.

When to use VLC / External Player: Some video files use audio or video formats that web browsers cannot play natively (for example, multi-channel AC3, EAC3, or DTS audio). If a video plays without sound or will not start in your browser, click the [ VLC / External Player ↗ ] button. This opens the stream directly in an external video player such as VLC Media Player, downloads a .m3u stream playlist, or lets you copy the direct network stream URL.

Video Player Keyboard Shortcuts
  • Space or K : Play / Pause
  • Left Arrow / Right Arrow : Jump backward / forward 10 seconds
  • Up Arrow / Down Arrow : Raise / lower volume
  • F : Enter or exit full screen
  • M : Mute or unmute audio

Reading & Accessing Books

The Books section contains digital publications organized into two formats:

  • PDF Documents: Selecting a PDF opens it in a browser viewing tab, allowing you to read, zoom, and navigate pages using your browser's built-in PDF viewer.
  • EPUB Books: Selecting an EPUB downloads the book file directly to your device so you can open it in your preferred e-reader application (such as Apple Books, Moon+ Reader, or Calibre).

Books that you have opened recently are listed at the top of the books catalog under Jump Back In for quick access.

Managing Files & Adding Media

Flan organizes your library by reading media files stored in its configured media directories on the host computer or attached USB storage:

DIRECTORY LAYOUT 
./media/video/<Movie Title>/movie.mp4
./media/video/<Movie Title>/poster.jpg
./media/video/<Series Title>/S01E01.mp4
./media/video/<Series Title>/poster.jpg
./media/books/<Book Title>.epub
./media/books/<Document Title>.pdf
  • Video Folders: Create a folder for each movie or show inside ./media/video/. To set custom cover art, place an image file named poster.jpg inside that folder.
  • Books: Place .epub and .pdf files directly into ./media/books/.
  • Storage Safety (.flan-keep): Flan verifies .flan-keep marker files inside each storage folder to protect your catalog from silent drive disconnections.

Updating the Library: After copying, moving, or renaming media files on disk, go to Manage Server and click [ Rescan All Media ]. Flan will inspect the directories and update your catalog with new and modified items.

Household Profiles & PINs

Flan supports multiple user profiles on a single server, allowing each family member to maintain their own watch progress, continue watching shelf, and reading records.

  • Switching Profiles: Click your avatar in the top-right header, select your account from the user grid, and enter your numeric PIN.
  • Updating Your Profile: Open the profile menu to change your display name, choose a new companion avatar preset, or upload a custom avatar photo.
  • Changing Your PIN: Enter your current PIN and choose a new 4-to-6 digit numeric PIN in your profile settings.
  • Managing Accounts: Server administrators can add new household members, update names, or reset forgotten PINs from the Manage Server page.

Command-Line Administration (CLI)

Flan includes terminal commands on the host system for administrative tasks and server configuration:

ADMINISTRATOR PIN RESET 
# Reset administrator PIN from the host terminal
./flan --reset-admin

If the administrator PIN is lost, run this command in a terminal on the server host machine. The program will prompt you to enter a new administrator PIN.

CUSTOM PORT CONFIGURATION 
# Start server on a specific network port (default: 4907)
PORT=8080 ./flan

By default, Flan listens on port 4907. Setting the PORT environment variable lets you configure the network port to match your homelab setup.

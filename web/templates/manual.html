1. About Flan Media Server

Flan is a self-hosted personal media server designed for streaming video files and reading digital books across household devices. Flan operates 100% offline with zero third-party metadata API calls.

Instead of CPU-intensive transcoding, Flan streams videos natively via standard HTTP 206 Range requests delegating directly to Linux kernel sendfile.

2. Interface Navigation

The interface features a persistent top header bar and a left navigation rail:

  • Search: Full-canvas interactive search across videos and books. Access via rail button or keyboard shortcut / or Ctrl+K.
  • Video: Browses movies and TV series catalog with Continue Watching shelf.
  • Books: Browses digital publications (EPUB and PDF) with Jump Back In shelf.
  • Manage Server: Administrator console for configuring storage folders, scanning media, and managing accounts.

3. Watching Videos & Player Controls

Flan includes the responsive Plyr media player. Your watch progress automatically synchronizes every 15 seconds.

Keyboard Controls:

  • Space / K: Play or Pause
  • F: Toggle Fullscreen
  • M: Mute / Unmute
  • Left / Right Arrow: Seek backward/forward 10 seconds

Unsupported Audio Codecs & VLC Streaming:

If your video uses multi-channel AC3, DTS, or Matroska (MKV) containers that your browser cannot decode, click the orange [ VLC / Download ] button. This generates a 4-hour signed link to stream directly in external players like VLC or MPV without transcoding.

4. Reading Books

Digital books support two formats:

  • PDF: Opens directly inside your web browser viewport.
  • EPUB: Direct file download to read on Apple Books, KOReader, or Calibre.

5. Storage Layout & Mount Markers

Flan protects your catalog from unmounted external drives using .flan-keep marker files:

  • ./data/.flan-keep: The server halts startup immediately if missing, preventing writes to an unmounted root partition.
  • <source_path>/.flan-keep: If an external drive disconnects, Flan safely flags its files as missing without dropping catalog entries or watch history.

6. Household Profiles & PINs

User accounts are protected by 4 to 6-digit numeric PINs. Failed login attempts are throttled with a dual-key rate limiter to prevent brute-force attempts without locking out other family members.

7. Host CLI Administration

If you lose your administrator PIN, reset it directly on the host shell: 

./flan --reset-admin

This interactively prompts for a new administrator PIN, updates SQLite, and immediately revokes all prior sessions.
